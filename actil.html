Lyon | Déc. 2024 – Aujourd'hui

Développeur Java — ACTIL

Groupe APICIL

📄 Présentation

Maintenance, fiabilisation et évolution d'un patrimoine de huit applications Java critiques, au sein d'une équipe Agile multi-technologies.

🧭 Responsabilités

  • TMA complète de 8 applications critiques Java legacy, reposant notamment sur un framework interne non documenté.
  • Référent technique sur le fonctionnement, la maintenance et l'évolution de ces applications.
  • Résolution d'incidents complexes et majeurs, dont certains ouverts depuis plus d'un an.
  • Revues de code régulières avec le Tech Lead Java.

🚀 Réalisations majeures

  • Participation au projet réglementaire EBD DENT-C, lié à la réforme du dispositif de prévention bucco-dentaire.
  • Développement en autonomie de l'application DENT-C en Java 17 / Spring, déployée en production début 2026, permettant à ACTIL de se positionner rapidement sur les évolutions du tiers payant dentaire.
  • Refonte de composants de signature XML utilisés par les flux ROC, afin de corriger des vulnérabilités sur des traitements exécutés plusieurs centaines de fois par heure.

🔧 CI/CD et fiabilisation

Amélioration et fiabilisation des pipelines CI/CD afin d'automatiser et de sécuriser les phases de build, de tests et de déploiement.

🤝 Équipe et méthodologie

Travail au sein d'une équipe Agile multi-technologies réunissant Java Legacy, Java Spring et IBM i / RPG, avec participation aux rituels :

  • Daily
  • Sprint Planning
  • Retrospective
  • Backlog Refinement

💻 Environnement technique

  • Java 17/21
  • Spring Boot
  • Java Legacy
  • CI/CD
  • XML
  • IBM i / RPG
  • Eclipse
  • IntelliJ IDEA
